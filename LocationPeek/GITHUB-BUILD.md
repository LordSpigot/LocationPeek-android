# APK ohne Android Studio bauen

1. Dieses Projekt in ein GitHub-Repository hochladen.
2. Im Repository auf **Actions** gehen.
3. **Build Location Peek APK** auswählen.
4. **Run workflow** anklicken.
5. Nach erfolgreichem Build unter **Artifacts** `LocationPeek-v1.0.0-APK` herunterladen.
6. ZIP entpacken und `LocationPeek-v1.0.0-debug.apk` auf dem HONOR Pad 10 installieren.

Danach unter Android **Entwickleroptionen > App für simulierte Standorte auswählen > Location Peek** einstellen.
